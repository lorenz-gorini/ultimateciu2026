### Live report contract

Use anonymous CORS CSV requests to the same workbook's `/gviz/tq`, explicitly setting `sheet=Foglio di gara (LIVE)`, `headers=0`, `tqx=out:csv`. Read metadata **C4:C7** with `tq=select *` separately from **C12:I200** with `tq=select C,D,E,F,G,I` (six returned columns; H is excluded). A whole-grid query was observed to discard mixed-type metadata; a CSV export with only a sheet name can silently select a roster tab. Neither is an acceptable fallback.

- Metadata must have the expected title/competition, an Italian calendar date equal to the fixture date, and both exact team names (or the approved alias). Reversed sides are explicitly reordered. Unknown spellings/date mismatches reject the overlay.
- The six body columns must match minute / squadra / assist / meta / parziale / break (the minute and break headers are blank in the actual export). Read cumulative scores from G and identify footer rows by labels, not row number. Goal increments must be coherent. A populated final-summary score must agree with the goal sequence. Actual start/end fields are in E beside halftime/final labels in F. Empty future templates can omit the hours/minutes colon. A label called risultato finale alone does not establish that the match ended.
- Requests omit credentials, use a 12-second timeout and 128 KiB response/CSV bounds. At most four match reports are in flight, with duplicate suppression. No JavaScript evaluation or persistent report-player cache. Aliases apply only to report identity; source names and evaluation URLs remain untouched. Scores and player data share this HTTP/identity boundary.
- `src/report-refresh.js` plans score checks over the whole selected division, independently of display filters. Automatic eligibility combines today's already-started/untimed games with the ±2-hour window around scheduled start; intervals are five minutes outside the open detail, 60 seconds inside it. A manual general refresh bypasses the interval and rechecks ended reports without main finals, within this window. An open detail can be forced even outside it. Automatic checks stop after main L/N is complete or a report records an actual end. Opening a match reads its goal history and roster/statistics once regardless of date; automatic repeats use the recovery window. Returning to visibility resumes only eligible checks. A shared four-worker queue coalesces overlapping requests; queued jobs from a departed division are skipped. An unchanged JSON poll cannot discard valid in-flight results; changed date/team/link/alias contexts cannot receive old overlays. Europe/Rome instants handle midnight and daylight-saving changes.
